# DUCK v0.10 Experiential Firewall Contract

This document is a binding interface contract for the v0.10 motivated-cognition candidate.

The technical requirement is partial access. DUCK's mechanistic substrate may contain numeric state, identifiers, scores, tags, graph activations, learned weights, confidence values, route utilities, motive strengths, need magnitudes, latent vectors, and other implementation representations. The simulated subject must not receive those representations as introspective content.

The subject may experience consequences of the machinery. It may feel tired, afraid, uncertain, curious, socially pulled, conflicted, familiar with something, unable to concentrate, or repeatedly drawn back to a concern. It may not inspect the substrate that produced those experiences.

The binding data path is:

```text
MECHANISTIC SUBSTRATE
numbers, tags, IDs, graph state, motives, modulation, scores
        |
        v
STRUCTURED INTERNAL PROJECTION
diagnostic assembly only
        |
        v
EXPERIENTIAL FIREWALL
translation + validation
        |
        v
EXPERIENTIAL FRAME
first-person experiential prose only
        |
        +----------------------+
        |                      |
        v                      v
PRIVATE COGNITION       PRIVATE INTERIOR RECORD
        |                      |
        |                      v
        |               versioned persistence
        |                      |
        +-----------+----------+
                    |
                    v
              RENDERER VIEW
          prose-only private context
                    |
                    v
              PUBLIC OUTPUT
```

## Data contract

`ExperientialFrame` is the only object that may cross from the subjective-access layer into a private cognition provider.

Its payload consists only of immutable first-person experiential prose strings. It contains no numeric fields, confidence values, intensity enums, action tags, channels, graph node identifiers, memory identifiers, plan identifiers, concern identifiers, motive identifiers, route scores, retrieval scores, latent state, or developer telemetry.

Structured `SubjectiveMoment` data may continue to exist as internal diagnostic scaffolding during migration from earlier DUCK versions. It is not the introspective API. A cognition provider must never receive it directly in the v0.10 runtime.

The experiential translator must reject content that represents mechanistic telemetry disguised as prose, including raw decimal state values, percentages used as confidence or magnitude reports, machine identifiers, key-value telemetry, activation values, route scores, retrieval scores, motive strengths, need magnitudes, and latent-vector descriptions.

The architectural rule is therefore stronger than "do not show floats." The character receives an experiential representation, not a sanitized debug packet.

## Private interior persistence

The current private interior must be durable across process restart.

Persistence uses a versioned `PrivateInteriorState` envelope. The persistence envelope may contain schema metadata required by the host, but schema metadata is not included in `ExperientialFrame` and is never introspectively accessible.

The persisted private interior contains the approved experiential prose and optional private inner speech. It does not contain the mechanistic snapshot, numeric need state, numeric affect state, action scores, motive strengths, activation graphs, or other developer telemetry.

A restart must restore the same supported private-interior schema and prose content. Unsupported schema versions must fail explicitly rather than being silently reinterpreted.

## Renderer contract

Public expression is generated by a renderer that may read a controlled prose-only view of the private interior. The renderer does not receive canonical subject state or raw mechanistic state.

Machine action identifiers must be translated into first-person intent prose before they enter the renderer packet. The renderer may receive a private thought as prose context, but public APIs and event journals must not return or serialize private thought merely because it was available to the renderer.

The renderer is an expression surface, not subject authority. It cannot write memories, beliefs, relationships, motives, plans, goals, or canonical private state directly.

Public interaction results must contain the rendered response and only explicitly public or developer-facing interaction metadata. They must not contain private experiential state or private thought fields.

## First-person doctrine

The firewall preserves point of view by enforcing a distinction between causal access and representational access.

A mechanistic energy state may cause the experience `I'm exhausted.`

A dominant restoration motive may cause the experience `I really need somewhere quiet.`

Associative activation may cause the experience `That flower just came back to mind.`

Threat-driven modulation may cause the experience `I don't feel safe enough to think about this right now.`

The subject may not receive `energy = 0.19`, `motive strength = 0.83`, `flower activation = 0.47`, `planning depth = 2`, or equivalent machinery descriptions.

This is not a stylistic preference. It is the technical mechanism that prevents the simulated first-person perspective from collapsing into omniscient access to its own implementation.

## Acceptance requirements

The v0.10 implementation must demonstrate that private cognition receives `ExperientialFrame` rather than `SubjectiveMoment`; that the frame is immutable and prose-only; that disguised telemetry is rejected; that language-lesion operation still refreshes experiential state; that private interior state survives persistence and restart with an explicit schema version; that the renderer packet contains prose intent rather than machine action tags; that public interaction results omit private thought and subjective-state fields; and that event journals do not publish private interior content.

These requirements are additive to the existing v0.10 subject-access firewall, language-lesion, persistence, longitudinal, autobiographical provenance, belief/world separation, and subject-authority requirements.
