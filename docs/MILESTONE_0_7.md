# DUCK Milestone 0.7: Thirty-Day Life Simulation

This milestone promotes long-horizon simulated life from a useful experiment to an acceptance requirement.

The milestone is complete when the v0.7 organism preserves the v0.6 authority boundaries while passing a deterministic thirty-day life simulation that includes recurring people, commitments, disappointment, repair, false testimony, direct contradictory evidence, repeated action/outcome learning, long quiet intervals, and multiple process restarts.

The subject-access firewall remains mandatory. Model-facing cognition and expression may receive qualitative first-person state but may not inspect raw numeric psychological telemetry, adaptive vectors, retrieval scores, or hidden causal annotations.

The thirty-day gate must demonstrate persistent identity across restart, autobiographical influence without explicit recall prompting, world-fact versus subject-belief separation, belief revision from stronger evidence, causal relationship trajectories, remembered broken commitments, later relationship repair without erasing adverse history, bounded quiet-time behavior, bounded numeric state, bounded memory/buffers, and measurable adaptive-core contribution under ablation.

Version 0.7 additionally requires that social action selection not collapse into repetitive questioning. Ordinary questions and supportive contact should generally create response affordances, while explicit repair contexts can create repair behavior. Recent-action inhibition may discourage perseveration but must not become a randomizer.

Safety must recover slowly after threat when no new danger occurs, without deleting threat memory. Competence must not remain saturated at 1.0 after a short run of successful outcomes. The thirty-day final state should therefore show recovery and normalization rather than permanent depletion or ceiling saturation.

Relationship history must support reinterpretation. A broken commitment remains an autobiographical fact, but later apology and kept commitments can change the present first-person interpretation from persistent undifferentiated wariness toward a mixed-history representation when current evidence warrants it.

The reference life-simulation command is:

```bash
python -m duck.life_simulation --out-dir simulation_results/life-v07
```

The full repository suite, original architecture probes, v0.6 regulation probes, preserved v0.5 and v0.6 simulation gates, and the v0.7 thirty-day life simulation must pass on Python 3.11 and Python 3.12 before promotion.

Passing this milestone establishes tested long-horizon causal coherence for the scenarios above. It does not establish phenomenal consciousness, human-equivalent cognition, or general psychological validity.
